# 로직 링크 — 생각을 잇는 서고

증명 30편과 작도 4편을 나누어 제공하는 카드 드래그앤드롭 게임. 계산·방정식 풀이·자료 정리 문제는 포함하지 않습니다.

## 조작
오른쪽 보관함의 카드 전체를 잡아 왼쪽 답안에 놓습니다. 카드 사이에 끼워 순서를 바꾸고, 보관함으로 되돌릴 수 있습니다. ddclass와 같은 @hello-pangea/dnd를 사용하며 마우스, 길게 누르는 터치, Space/방향키/Escape 키보드 조작을 지원합니다. 독립적인 근거의 순서는 여러 타당한 배열을 인정합니다.

## 실행
`npm ci`, `npm test`, `npm run build`, `npm start`. Vercel은 npm run build 및 dist를 사용합니다.

진행은 안정된 책 ID로 보존하며 삭제한 문제는 목록·진행률에서 제외합니다. 증명용 튜토리얼과 생각 노트는 별도 기록으로 저장합니다. 교과서 PDF 및 내부 추출문은 포함하지 않습니다.

## 배경음악과 학년 선택
첫 화면의 중학교 1·2·3학년 버튼에서 해당 서가를 열 수 있습니다. 기존 학년 분류를 유지하며 작도 4편은 중학교 1학년 서가에 있습니다.

배경음악 메뉴에서 집중/활력 모드와 음량을 고르고 재생합니다. 효과음은 별도 조작합니다. 같은 페이지에서 책을 변경하거나 서가를 여는 동안 하나의 오디오 요소가 계속 재생됩니다. 일시정지 후 재생은 같은 위치에서 이어집니다. 모드·음량은 이 브라우저에 저장되지만 새로고침 뒤에는 사용자가 재생을 눌러야 합니다. 생각 노트처럼 다른 페이지로 이동하면 음악은 멈춥니다.

음원은 외부 샘플 없는 오리지널 신시사이저 연주이며 `node scripts/compose-music.mjs`로 다시 생성할 수 있습니다. 파비콘은 책과 연결된 근거를 나타내는 SVG입니다.
